# BiteFlow UI Context

## Product feeling
Real restaurant product, not a generic SaaS dashboard.
Premium, elegant, warm, food-focused, clean, practical.

## Brand
BiteFlow wordmark. Warm food tones.
Starting tokens: chocolate #3A2118, warm orange #E86A2A, golden #F2B544, cream #FFF8EF, dark #17110E.

## Theme
Every interface supports light and dark mode.

## Customer UI
Food imagery, categories, clear prices, food details, persistent cart, simple checkout, clear payment state, clear order status.

## Admin UI
Fast scanning, tables, filters, status badges, order workflow, reports, practical controls.

Avoid excessive gradients, glassmorphism, unnecessary effects, or AI-dashboard styling.

## UX
Clear loading/empty/error states. Confirm destructive actions. Never rely on color alone for status. Responsive mobile and desktop.
