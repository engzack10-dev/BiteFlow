# FS-02 — Menu & Categories

## Goal
Allow the admin to manage the restaurant menu.

## Requirements
- Admin can create, edit, and delete categories.
- Admin can create, edit, and delete products.
- Product has name, description, image, price, category, and availability/status.
- Admin can mark a product available or unavailable.
- Customers can only purchase available products.
- Product images use the BiteFlow brand/product presentation.
- Menu changes are reflected in the customer storefront.

## Acceptance Criteria
- Product CRUD works.
- Category CRUD works.
- Products are correctly linked to categories.
- Unavailable products cannot be added for purchase.
- Customer menu shows current product data.
