# FS-08 — Customer Order Tracking

## Goal
Allow customers to see the progress of their own orders.

## Requirements
- Customer can view their orders.
- Customer can open an order detail page.
- Customer can see payment status.
- Customer can see current order status.
- Customer can see delivery information.
- Customer cannot view another customer's order.

## Acceptance Criteria
- Customer sees current order state.
- Status changes are reflected correctly.
- Access to another customer's order is denied.
- Delivered orders remain available in the customer's authenticated history.
